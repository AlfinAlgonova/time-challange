⏱️ PYTHON TIME CHALLENGE

"Mastering Time with Python"

Latih kemampuanmu menggunakan time.sleep(), time.time(), countdown, stopwatch, dan reaction time!

📚 QUICK REVIEW

Sebelum mulai bertanding, yuk pahami materi dasar berikut ini!

1. Import time

import time

Penjelasan: time adalah library bawaan Python yang dapat digunakan untuk bekerja dengan waktu.

2. time.sleep()

time.sleep(3)

Penjelasan: Program akan berhenti sementara selama 3 detik.

Contoh:

import time

print("Mulai!")
time.sleep(3)
print("Selesai!")

3. time.time()

waktu = time.time()

Penjelasan: time.time() digunakan untuk mendapatkan waktu saat ini dalam bentuk angka detik unik (timestamp).

4. Menghitung Selisih Waktu

awal = time.time()
# proses yang diukur
akhir = time.time()

hasil = akhir - awal
print(hasil)

Penjelasan: Selisih akhir - awal digunakan untuk mengetahui berapa lama sebuah proses berlangsung.

💡 Catatan: time.time() menggunakan satuan detik.

Soal 4 — Mengukur Waktu

Gunakan time.time() untuk menghitung berapa lama sebuah proses berlangsung. Simpan waktu awal, buat program jeda 3 detik, simpan waktu akhir, lalu hitung selisihnya.

💡 Hint: Gunakan rumus akhir - awal untuk mendapatkan durasi selisih waktu. 
import time

awal = time.time()
time.sleep(3)
akhir = time.time()

hasil = akhir - awal
print("Program berjalan selama", hasil, "detik")

Soal 5 — Stopwatch

Buat program stopwatch sederhana. Program meminta pengguna menekan ENTER untuk mulai, lalu menekan ENTER lagi untuk berhenti, dan tampilkan waktu yang berlalu dalam detik.

💡 Hint: Catat time.time() tepat setelah perintah input() dipanggil. 
import time

input("Tekan ENTER untuk mulai...")
awal = time.time()

input("Tekan ENTER untuk berhenti...")
akhir = time.time()

hasil = akhir - awal
print("Waktu:", round(hasil, 2), "detik")

Soal 6 — Reaction Time

Soal 7 — Timer 10 Detik

Buat timer countdown dari angka 10 sampai 1 dengan jeda 1 detik per angka. Setelah hitungan selesai, tampilkan: ⏰ Waktu habis!.

💡 Hint: Gunakan perulangan mundur range(10, 0, -1).

Soal 8 — Batas Waktu Input

Buat program yang memberi waktu maksimal 10 detik bagi pengguna untuk memasukkan nama. Jika berhasil ≤ 10 detik cetak "Jawaban diterima!", jika lebih cetak "Waktu habis!".

💡 Hint: Gunakan percabangan if hasil <= 10: setelah mengukur durasi selisih input. 
import time

awal = time.time()
nama = input("Masukkan nama kamu: ")
akhir = time.time()

hasil = akhir - awal

if hasil <= 10:
    print("Jawaban diterima!")
    print("Waktu:", round(hasil, 2), "detik")
else:
    print("Waktu habis!")
    print("Kamu membutuhkan", round(hasil, 2), "detik")

Soal 9 — Time Challenge Game

Buat game tebak angka 1–10 secara acak dengan batas waktu menjawab 10 detik. Periksa apakah tebakan benar dan tidak melebih batas waktu.

💡 Hint: Import randint dari library random. Cek durasi waktu menggunakan if waktu > 10: terlebih dahulu. 
import time
from random import randint

angka_rahasia = randint(1, 10)

awal = time.time()
tebakan = int(input("Tebak angka 1-10: "))
akhir = time.time()

waktu = akhir - awal

if waktu > 10:
    print("⏰ Waktu habis!")
elif tebakan == angka_rahasia:
    print("🎉 Kamu menang!")
    print("Waktu:", round(waktu, 2), "detik")
else:
    print("❌ Tebakan salah!")
    print("Angka yang benar:", angka_rahasia)

Soal 10 — Speed Typing Challenge

Buat game ketik cepat! Tampilkan kata "PYTHON", catat waktu mengetik user, dan validasi apakah kata yang diketik benar.

💡 Hint: Ambil timestamp sebelum input() dan sesudah input(), lalu cocokkan variabel jawaban dengan string "PYTHON". 
import time

print("Ketik kata berikut:")
print("PYTHON")

awal = time.time()
jawaban = input("Ketik: ")
akhir = time.time()

waktu = akhir - awal

if jawaban == "PYTHON":
    print("Benar!")
    print("Waktu kamu:", round(waktu, 2), "detik")
else:
    print("Jawaban salah!")
